# SHAPE mobile

SHAPE for Android is a portrait-only Go study app. It lets you play against a
human-policy model at a chosen rank and compare each move with the policy at your
rank and the rank you are working toward. Inference runs on the phone; the app
does not need a network connection or account.

## Features

- 9×9, 13×13, and 19×19 games
- an opponent sampled from KataGo's human-SL policy at a selected rank
- optional feedback after mistakes or after every move
- policy overlays for your rank, your target rank, or the professional profile
- a move tree: playing from history creates a variation, and explored next moves
  remain marked on the board
- review and previous/next-mistake navigation
- a board-only fallback when the model cannot run

The default presentation is intentionally restrained: the policy is hidden while
you decide, and post-move feedback appears only for moves classified as mistakes.

## Runtime

```text
move -> GoPosition.play
     -> Features.fillRowFeatures   22 board planes + 19 globals
     -> SgfMetadata.getMetadataRow 192 profile channels
     -> MNN CPU                    b18c384nbt-humanv0
     -> policy + lead + outcome    opponent, feedback, score, and win estimate
```

`lib/engine/board.dart` and `lib/engine/features.dart` port the corresponding
KataGo Python code. The board implementation includes the ladder search needed by
feature planes 14–17. It stays close to the source because those features depend
on KataGo's incremental group bookkeeping.

MNN is used for gameplay. On a Galaxy S24+ it measured about 104 ms per profile,
roughly twice as fast as the earlier ONNX Runtime path. Only MNN's CPU backend is
shipped: OpenCL did not improve the measured time and Vulkan was unstable.

## Tests

From this directory:

```sh
flutter test
flutter analyze
```

The tests do not require an emulator or model. The main coverage is:

- `featurizer_test.dart`: exact comparison of all feature planes and globals with
  fixtures generated by KataGo, including ladders, ko, captures, passes, and all
  supported board sizes
- `sgf_metadata_test.dart`: all metadata channels across representative profiles
- `shape_game_test.dart`: move-tree behavior, navigation, analysis caching,
  opponent sampling, feedback, and queued setting changes
- `policy_data_test.dart`: legal-move filtering and pass sampling
- `verdict_test.dart`: the feedback classification thresholds

## Build

CI exports and converts the model, downloads the MNN Android libraries, runs the
tests, and builds a sideload-signed arm64 APK. The workflow attaches the APK to
the pull request.

For a local build, provide `assets/humanv0.mnn` and the required arm64 MNN shared
libraries under `android/app/src/main/jniLibs/arm64-v8a/`, then run:

```sh
flutter build apk --release --split-per-abi --target-platform=android-arm64
```

The exact export, conversion, and native-library steps are in
`.github/workflows/mobile_apk.yml`. `tools/mnn/mnn_parity.py` checks the converted
model against the ONNX source.

## Regenerating fixtures and model inputs

With KataGo's `python/` directory on `PYTHONPATH` and the
`b18c384nbt-humanv0.ckpt` checkpoint available:

```sh
cd tools/onnx_export
python export_onnx.py
python export_assets.py
python export_fixtures.py
```

`export_onnx.py` compares the export with KataGo. That check requires
`nnRandomize = false` and `useFP16 = false`; see `deterministic.cfg`.

## Limits

- The score and points-lost estimates come from the human-SL model's lead head at
  the professional profile, without search. They are useful approximations, not
  the same values as desktop SHAPE's searched KataGo analysis.
- Only Japanese territory scoring is supported. Area scoring needs KataGo's
  pass-alive calculation, which is not ported.
- The board implements simple ko, not superko, matching the Python reference used
  by the featurizer.
- The automatic opponent passes by sampling the pass probability. There is no
  separate searched endgame policy.
- MNN is disabled on the Android emulator because its advertised ARM features can
  make the native library select instructions the emulator does not implement.
  The app then remains usable in board-only mode.

One scoring detail is easy to lose: under territory scoring, KataGo's self-komi
frame shifts by one point per non-pass stone. `_pointsLost` removes that shift so
ordinary moves do not all appear to lose about one point.
